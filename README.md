# Kakeibo, budget à la japonaise

Une appli de kakeibo pour iPhone et Android : on note soi-même ses dépenses, on clôture sa journée chaque soir, et cette régularité fait vivre une maison japonaise. Hors ligne, sans compte, sans lien bancaire.

- **Ce qu'il faut construire :** [docs/spec.md](docs/spec.md), copie du [document de spécifications](https://claude.ai/artifact/71tMXdJNxRnPD14BioaLJb).
- **Comment les agents travaillent :** [CLAUDE.md](CLAUDE.md).
- **Le découpage en tickets :** [docs/backlog.md](docs/backlog.md), puis les issues du dépôt.
- **Mettre les agents en route :** [docs/agents.md](docs/agents.md).

Le code arrive avec le jalon J0 : projet Expo, intégration continue (types, lint, tests sur chaque demande de fusion), base locale.
